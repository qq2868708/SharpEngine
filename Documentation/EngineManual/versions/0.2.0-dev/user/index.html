开始使用

创建或打开项目后，可以在编辑器中搭建场景、配置资源并预览结果，也可以启动独立运行模式检查游戏中的表现。

编辑器允许在没有现成项目内容时从空白状态开始；运行模式需要一个有效的启动场景。项目会记录所使用的引擎版本，保证团队成员看到一致的内容和行为。

编辑器工作流

编辑器提供视口、层级、资源浏览、属性检查、界面编辑和日志查看等面板。播放会使用当前已保存的内容创建独立的运行副本；停止后，运行期间的临时变化会被清除。

层级、变换、资源选择和设置编辑都支持撤销、重做和恢复。编辑器会在内容变化后重新载入可用结果；如果载入失败，会保留当前编辑状态并显示诊断信息。

资源浏览器支持按文件夹、名称、来源和类型查找内容，多个浏览器可以分别保留自己的位置、筛选条件和选择。单击文件夹只选择它并保持当前目录，双击文件夹才进入目录；文件夹图标和名称遵循相同规则。资源仍然是单击选择、双击打开。

动画时间轴与 Notify

编辑器的 Animation Timeline 面板提供骨骼采样预览、时间尺、轨道、播放头和预览控制。预览会按骨骼父子层级累积姿态，并根据整套骨架范围自动取景，避免关节越界或连线被拉到面板外；播放到末尾后会显示完成状态。打开 View 菜单中的 Animation Timeline 后，可以使用 Play、Pause、Stop 和时间尺按钮检查动画片段。

在 Content Manager 中单击资源只选择它；双击 SkeletalAnimation 资源会打开对应的 Animation Timeline 文档。Windows 原生鼠标双击和自动化指针双击都会走同一套资源打开流程。Notify 轨道显示 Footstep、Attack Window 等事件。点击 Clip 可以查看当前 Notify，使用 Add Notify 会在预览时间线上创建新的事件并立即刷新视图。每个打开的资源保留自己的播放头、Undo、Redo 和 dirty 状态；项目资产支持 Save，引擎来源资产保持只读。关闭浮动 Animation Timeline 后再次双击资源会重新创建并保留该面板，仍然沿用同一套资源打开流程。

Viewport 的 Transform 按钮和项目 Project Preview 按钮都通过引擎命令执行。项目可以扩展固定的 File 菜单、主 Toolbar 和 viewport CustomBar Surface，但不能创建新的顶层 Surface。

世界与资源

场景支持实体、父子层级、变换、相机、导航、网格、材质和动画等内容。可以把一组实体保存为可重复使用的预制内容，并在其他场景中创建独立实例。

源资源是可编辑内容的唯一依据；运行和发布过程中产生的构建结果可以重新生成。无法识别的内容会被保留并提示问题，不会悄悄变成可运行对象。

FBX 导入与导出

FBX 是导入来源格式。导入后，项目使用 SharpEngine 的骨骼、蒙皮网格和动画资产；FBX 文件应保留在 Content 之外的来源目录。需要来源校验时，在资产中记录 sourcePath 和 sourceSha256，引擎会验证来源文件是否仍然匹配。验证来源不代表当前资产编辑仍能由该来源还原。

导出使用语义等价规则。网格几何、坐标系和单位，骨骼层级与绑定姿态，蒙皮权重，以及动画的骨骼轨道必须保持等价。导出器可以重新组织 FBX 记录、压缩方式和未建模的元数据，因此导出文件的字节内容不需要与导入文件相同。

通过资产的 ExportFbx 或 AssetContent.ExportFbx 入口导出。当前内置路径只复制显式注册的原始 FBX 来源；对规范化 SharpEngine 资产会报告尚未接入 FBX writer 且不改写目标文件。接入 writer 后从当前 SharpEngine 数据重建文件。完成后重新导入导出文件并检查上述语义数据；重新导入检查通过才算完成格式验证。

跨骨骼组复用动画时，先用 SkeletalAnimationCompatibility.Validate 检查动画和蒙皮网格。A 动画直接绑定 C 网格会被拒绝；使用 SkeletalAnimationRetargeter.Retarget 明确提供源/目标骨骼映射后，会生成指向 C 骨骼的新动画资产，再按普通兼容性规则与 C 蒙皮网格组合。当前 Retarget 不自动猜测骨骼、不做 IK 或比例补偿，FBX writer 仍未接入。

控制与移动

让角色或其他对象接受玩家或 AI 的控制，并按照移动意图在场景中移动。控制来源和移动能力彼此独立，因此同一套移动行为可以服务不同的控制方式。

当多个控制来源指向同一个对象时，引擎会按照优先级选择一个来源，保证结果稳定。对象不可用、控制冲突或控制暂时失效时，运行状态会显示相应诊断。

引擎默认示例包含 prefabs/capsule-character 胶囊体角色 Prefab，并已实例化到引擎的 Content/Worlds/Main.sworld。在编辑器按 Play 后点击 Viewport 使其获得焦点，使用 WASD 移动角色；Stop 会丢弃运行时位置变化。

示例 Prefab 和主场景使用 UEFN mannequin 骨骼角色，状态机会根据移动速度在 Idle、Walk、Run 之间切换，并保留 Jump 状态入口；胶囊只作为不可见的 Trace 碰撞体，随角色移动。状态机和动画依赖加载失败时会保留诊断，不会静默回退到错误 Clip。Content Manager 双击引擎提供的 AnimationStateMachine 预设会沿用统一资源打开流程，在 Animation Timeline 面板显示状态与过渡图；该引擎预设保持只读。验证入口与范围见下方专题文档。

功能边界、可观察状态和使用限制见 控制、可控制目标与移动专题文档。

输入与 UI

键盘和鼠标会先交给当前获得焦点的界面。界面可以处理点击、滚动、文本输入和指针捕获；未被界面使用的输入再交给编辑器或游戏逻辑。Ctrl+Z 撤销，Ctrl+Y 或 Ctrl+Shift+Z 重做，F5 播放或暂停，F8 停止。文本输入框获得焦点时优先处理自身的编辑操作。

编辑器界面和运行时界面都可以使用统一的操作映射，因此同一个操作在不同界面中能够保持一致的响应方式。Play 或 Pause 时，Viewport 的相机导航、选择和 Gizmo 不再接收游戏输入；输入只作用于运行时逻辑，Stop 后恢复编辑操作。

设置与模块

引擎设置和项目设置使用统一的属性面板编辑。修改会即时检查有效性，支持撤销、重做和恢复，保存后才会成为项目内容。

功能模块可以只服务编辑器、只服务运行模式，或同时服务两者。启动时会按照依赖关系载入模块，停止时会按相反顺序清理。

网络与 Dedicated Server

网络模块提供版本化 Schema、服务器 Command 路由、幂等结果和基于 RuntimeFrame 的完整快照/字段差分。DedicatedServerSession 使用现有 RuntimeWorld 的固定 Tick 和提交边界运行权威模拟。

UdpNetworkTransport 提供可运行的 C# UDP 收发，支持可靠有序投递、快照 ACK、连接超时和 payload 预算。服务器在 World 线程处理入站 Command，客户端只有在 Schema 指纹匹配并完成握手后才能发送 Command。项目默认只生成 Editor/Game；需要 Dedicated Server 时，在 Windows 资源管理器中右键项目的 .sharpproject 文件，选择 Add Server Target（Windows 11 可先选择“显示更多选项”）。该操作自动保存 Target 并重新生成工程文件，Rider 重新加载 solution 后即可使用 Server Target。QUIC、生产认证和客户端预测仍是后续工作。使用方式和验证命令见 网络、属性同步与 Dedicated Server 基础。

验证边界

功能验证分为内容检查、编辑器检查、运行检查、构建检查和发布包检查。某一层通过，只能说明该层的行为符合预期，不能替代其他层的验证。

每个功能页面都会说明适用的验证范围和已观察到的结果；遇到问题时，优先查看对应功能的诊断信息和验证记录。

数据资产

项目可以用 C# 数据类型定义独立的配置资产，将同一种配置类型保存为多个 .sdataasset 文本资源，并通过稳定资产 ID 加载。字段约束和直接资源引用会在加载时校验。抽象基类可以复用字段，具体派生类各自声明资产类型；sealed 不是必需的。

当前提供类型、Schema、强类型加载和显式文件保存基础；通用创建菜单、Inspector 文档和撤销事务仍待接入。Editor 项目代码重载会重新发现 Runtime Module 中的具体数据资产类型，并更新 assets.describe 与 sharpengine://assets 的 Schema。使用方法和验证边界见 数据资产专题。

本版更新

  • 修正 mannequin Walk/Run 示例 Clip 的局部关节旋转轴和幅度，移动采样时四肢保持连续；Animator、Playable 和状态机契约不变。
  • 场景渲染增加基础环境光，骨骼模型背向方向光时仍保留可读的体积和关节轮廓；Sandbox 主相机调整为角色近景构图，便于检查蒙皮与动画姿态。
  • 新增可序列化的最小动画状态机，示例 mannequin 会根据移动速度在 Idle、Walk、Run 和 Jump 状态间切换。
  • 登记只读 builtin/preset locomotion 状态机，并通过统一资源打开器在 Animation Timeline 面板提供状态图编辑器视图。
  • 增加由 C# 类型声明的版本化数据资产基础，支持字段约束、直接资产引用校验、继承字段和基类多态加载。
  • 项目 Runtime Module 重载会重新发现具体 DataAsset 类型；资产 MCP 查询现在稳定返回继承字段和派生字段的 Schema。
  • 建立版本化 HTML 手册入口，拆分为用户手册和 API 索引。
  • 定义功能修改必须同步更新手册并运行手册链接校验的维护约束。
  • 补充控制器、可控制目标和移动组件的用户工作流与运行时边界。
  • 新增胶囊体角色 Prefab、主场景实例和 WASD Play 移动验收流程。
  • Sandbox 角色改用 UEFN mannequin 骨骼网格和循环 Walk 采样；胶囊体保留为不渲染的 Trace 碰撞组件。
  • 用户手册改为只描述功能用途、操作结果和使用限制；实现接口集中在 API 索引。
  • 增加 C# UDP transport、Schema 握手、快照 ACK、Command 收发和客户端 Replica。
  • 增加 Server Target 与 Examples/NetworkDedicatedServer 示例，验证原生 Dedicated Server 加载 Runtime Module、双客户端位置同步和重复命令幂等。
  • Server Target 改为项目级可选项；资源管理器右键 .sharpproject → Add Server Target 会更新项目 manifest 并自动生成工程文件，Remove Server Target 会清理对应生成文件。
  • 修正 Animation Timeline 骨骼预览：按父子层级累积姿态并自动取景，播放结束时显示完成状态；Notify 编辑继续使用 revision/Undo/Redo/Save 流程。
  • 增加按资产双击打开 Timeline 工具的路由；项目或插件可以按 AssetId、资产类型和优先级覆写默认打开器；浮动 Timeline 关闭后可立即再次打开并复用统一生命周期。
  • 统一 FBX 导入来源校验和语义等价导出规则；导出不再要求保留原始 FBX 字节。
  • 增加显式骨骼动画 Retarget 验证：跨组动画必须生成目标 SkeletonId 的新资产，并通过目标蒙皮绑定检查后才能组合。
  • 修正编辑器修饰键位映射，并在 Play/运行时隔离 Viewport 编辑输入，避免游戏移动同时驱动编辑器相机。
  • 修正 Windows 原生双击消息在 Content Manager 中只触发一次选择的问题；真实鼠标双击现在会打开对应资产编辑器。
  • 修正 Content Manager 文件夹交互：单击文件夹只选择并保持当前目录，双击文件夹进入目录，图标和名称使用相同动作。
