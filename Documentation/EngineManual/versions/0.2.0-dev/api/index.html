API 条目

SharpEngine.Runtime

RuntimeWorld、World、组件注册、实体和序列化入口。Authoring 数据是权威状态，Runtime World 从最近提交快照重建。

相关稳定身份包括 engine.transform、engine.camera、engine.static-mesh 和已注册的项目组件 typeId。

SharpEngine.Editor.EditorRuntime

提供 Editor 生命周期、场景/资源/编辑器快照、命令注册和项目代码重载的语义入口。编辑器命令同时服务 UI 点击和 MCP 调用；EditorPaneIds.Timeline 是引擎创建的 Animation Timeline 面板。

IMenuExtension、IToolBarExtension 和 ICustomBarExtension 分别扩展固定 File 菜单、主 Toolbar 和引擎创建的 viewport/timeline CustomBar。CustomBar 的 Append/Replace 只影响显示，命令注册仍然保留；扩展不能创建或删除顶层 Surface。

SharpEngine.Runtime.Input

InputAction、InputMappingContext 和统一输入路由。动作回调返回 true 时消费动作；事件顺序和 route 名称属于可观察契约。Win32/RmlUi 修饰键位遵循 Ctrl=1、Shift=2、Alt=4；编辑器 Play 状态下，Host 不再把事件转发到 EditorRuntime 的 Viewport 导航、选择或 Gizmo 入口。

SharpEngine.Animation.AnimationStateMachineAsset

状态机资源使用 .sanimationstatemachine 和 schema v1，保存稳定的参数、状态、Clip 依赖和有序过渡。AnimationStateMachineContent.Load 先解析完整图并绑定所有骨骼动画；AnimationStateMachineAsset.SelectTransition 按资源顺序检查 exitTime 和数值条件。engine://animation-state-machines/uefn-mannequin-locomotion 在 engine manifest 中以 readOnly=true、builtin 和 preset 标签登记，并声明 mannequin skeleton 与四个 Clip 依赖。

Content Manager 的双击和语义打开都调用 EditorRuntime.OpenAsset；统一的 EditorAssetOpenerRegistry 通过 engine.animation-state-machine-editor 将该类型路由到 Animation Timeline 面板中的状态图视图。浮动面板关闭期间的 native host 会在当前窗口回调结束前完成延迟销毁，保证下一次打开复用 host ID 时不会误销毁新面板。

AnimatorComponent schema v3 的 Controller、StateId、Parameters、MovementSource 和 MovementSpeedParameter 是权威字段；运行帧 schema v2 公开当前状态、过渡、参数和采样结果。旧 Animator v1/v2 只补齐控制器字段，不改变既有单 Clip 语义。

SharpEngine.Components 控制与移动

ControllableComponent、ControllerComponent、PlayerControllerComponent、AiControllerComponent 和 MovementComponent 使用组件 typeId schema v1。控制器通过 SetMoveInput 提交当前帧意图；移动组件依赖 Transform 和 Controllable，并发布稳定的诊断 code 与速度 frame state。

绑定仲裁、运行时字段和示例见 控制、可控制目标与移动专题文档。

prefabs/capsule-character

资源类型为 Prefab，源文件为 Content/Prefabs/CapsuleCharacter.sprefab，使用 World/Prefab JSON schema v3。根实体包含 engine.skeletal-mesh（engine://meshes/uefn-mannequin）、engine.animator、engine.capsule-collider、控制与移动组件；engine.player-controller.ControlledEntity 指向根实体稳定 ID，实例化时必须重映射实体和组件引用。

示例 Prefab 使用 engine.skeletal-mesh schema v1（engine://meshes/uefn-mannequin）和 engine.animator schema v3，绑定 engine://animation-state-machines/uefn-mannequin-locomotion。实例化同时重映射 Target 和 MovementSource；胶囊 collider schema v1 提供 RuntimeWorld.Collision.Raycast 查询且不生成渲染几何。动画复用 Playable 采样，SkeletonFrameState 的骨骼矩阵和蒙皮顶点属于派生帧数据，不保存进 Prefab/World。

SharpEngine.Timeline

IPlayable、PlayableGraph、TimelineDocument、TimelineView、TimelineAuthoringSession、AnimationNotify 和 MarkerPlayable。编辑器扩展通过 timeline.play、timeline.pause、timeline.stop、timeline.add-notify、timeline.undo、timeline.redo、timeline.save 和 timeline.seek-start 命令驱动预览与编辑。

SharpEngine.Networking

NetworkSchemaCatalog 登记稳定的组件属性和 RPC 描述；NetworkCommandRouter 只执行显式注册的 Command，并按 ConnectionId + MessageId 缓存幂等结果。

NetworkReplicationFrameBuilder 从不可变 RuntimeFrame 生成完整快照或基于 NetworkReplicationBaseline 的字段差分。DedicatedServerSession 运行权威 Runtime Tick 并返回 NetworkServerFrame。

UdpNetworkTransport 基于 LiteNetLib 提供 C# UDP、MTU 分片、CRC32C、连接超时、四种可靠性和四条通道；DedicatedServerNetworkHost 提供 Schema 指纹握手、Command 权限入口、每连接 baseline/ACK；NetworkClientSession 和 NetworkReplicaState 提供客户端握手、Command 发送和原子快照应用。当前协议版本为 NetworkProtocol.SchemaVersion = 1；QUIC、生产认证和客户端预测不属于本阶段公共实现。

INetworkServerRuntime 是 Server Runtime Module 的注册契约，提供 NetworkSchemaCatalog、RegisterCommand、权限和相关性策略入口；Server Target 的原生入口为 DedicatedServer.exe。项目 manifest 的 targets 数组控制生成的 Target；默认值为 ["Editor", "Game"]，Project Selector 的 add-target --target Server 和 remove-target --target Server 原子更新该契约。Windows 文件关联的 AddServerTarget 和 RemoveServerTarget shell verb 分别调用这两个命令，随后自动重新生成工程文件。

EditorAssetOpenerRegistry

Register(EditorAssetOpener) 注册按 AssetType 或具体 AssetId 匹配的打开器，并返回可释放句柄；具体资源优先于类型匹配，同级按 Priority 选择。EditorRuntime.OpenAsset 是 UI 双击和 MCP/语义调用共用的打开入口，DescribeEditorJson().assetTools 暴露注册器与工具状态。

版本化 JSON 与 MCP

AI-facing snapshot、组件、资产、设置和输入契约包含 schemaVersion。未知未来版本、未知必需类型和迁移失败必须返回结构化诊断；不能静默丢弃字段。

SharpEngine.Assets.FbxSourceContract

ExportFbx(AssetRegistry, Id, Destination) 定义 Mesh、StaticMesh、Skeleton、SkeletalMesh 和 SkeletalAnimation 的语义导出入口。当前内置实现只复制显式注册的原始 FBXSource；规范化资产返回 NotSupportedException 且不修改目标。sourcePath/sourceSha256 只能校验来源未变，不能证明已经编辑的当前资产与来源仍然语义一致。接入 FBX writer 后，编辑后的规范化资产必须从当前数据重建。

StaticMeshAsset、SkeletonAsset、SkeletalMeshAsset、SkeletalAnimationAsset 和 AssetContent 都提供同名 ExportFbx 包装入口。旧的 ExportOriginalFbx 只作为标记为 obsolete 的来源复制入口。

SharpEngine.Animation.SkeletalAnimationCompatibility 与 SkeletalAnimationRetargeter

SkeletalAnimationCompatibility.Validate(Animation, Mesh) 是普通组合的显式检查：比较 SkeletonId、骨骼身份、父子关系和绑定局部 TRS；失败时抛出输入错误，绝不隐式重定向。

SkeletalAnimationRetargeter.Retarget 接收源动画、源/目标 Skeleton 和完整 BoneMap，创建新的 SkeletalAnimationAsset 并把 SkeletonId 指向目标 Skeleton。输出保留时长、采样率、Notify 和关键时刻，并通过绑定姿态 Delta 计算目标局部 TRS。当前没有 IK、比例补偿、自动命名匹配或独立 RetargetMap 资产；调用方应在输出后再次调用兼容性检查。

数据资产 API

DataAsset 支持抽象基类和继承属性；每个可加载的具体派生类型使用 DataAssetTypeAttribute 声明稳定类型 ID，sealed 可选。DataAsset<T> 是叶子类型的便捷基类，DataAssetFactory.Create<T> 可创建任意具体派生类型。DataPropertyAttribute、DataAssetTypeRegistry 和 DataAssetSerializer 定义第一阶段数据资产契约。.sdataasset 使用类型声明的 schemaVersion，封套包含 schemaVersion、kind、assetId 和 name；manifest type 等于稳定类型 ID。

支持显式注册与程序集发现、属性描述和 JSON Schema、确定顺序序列化、强类型加载、范围与直接引用校验、只读保护和临时文件替换。DataAssetTypeRegistry.Load<TBase> 会按 manifest 类型创建具体派生值并返回可赋给基类的实例。Editor 的 Runtime Module 重载会原子替换项目数据资产类型注册表，并在失败时恢复旧注册表；assets.describe 与 sharpengine://assets 暴露当前类型和 Schema。该 API 不提供编辑器事务或完整 Cook。详见 数据资产专题。

本版更新

  • 更新 engine://animations/uefn-mannequin-walk 与 engine://animations/uefn-mannequin-run 的生成数据：局部肢体旋转使用与 mannequin 绑定骨架相符的轴向和受控幅度；SkeletalAnimation schema 仍为 v1，engine.animator schema v3 不变。
  • SceneRenderer.BuildFrame 的三角面光照包含固定基础环境光项，方向光为零或背向时仍输出可观察的材质颜色；该项属于派生渲染数据，不改变场景资产 schema。
  • 新增 AnimationStateMachineAsset 与 engine.animator schema v3；状态、参数、过渡和全部 Clip 依赖可从快照重建。
  • 登记 engine-owned、只读、builtin/preset 的 mannequin locomotion 状态机，并复用 EditorAssetOpenerRegistry 的统一打开流程。
  • 增加数据资产类型声明与 .sdataasset 封套契约，类型 schema 从 v1 起显式声明；支持抽象基类、继承字段和基类多态加载；未引入已有资产格式迁移。
  • Runtime Module 重载现在重新发现 DataAsset 类型并以原子注册表提交；失败回滚保留之前的类型发现结果，资产 MCP 查询使用同一快照。
  • 建立首版 API 索引，收录引擎 manifest、项目、World、输入、编辑器、Timeline、设置和日志契约。
  • Timeline 编辑器预览现在按骨骼父子层级从局部变换重建模型姿态，并按骨架范围自动取景；播放完成状态属于瞬态编辑器状态，Timeline 资产 schema 仍为 v1。
  • 增加 SkeletalAnimation 双击打开路由、独立 Timeline 文档状态以及 EditorAssetOpenerRegistry 的项目覆写契约；明确浮动 Timeline 关闭后立即重开的 host 生命周期保证。
  • 规定新增或修改公共类型、稳定 ID、命令、MCP 能力和 schema 时必须同步更新本页。
  • 收录控制与移动组件的 typeId、schema 和 frame state 入口。
  • 增加 SharpEngine.Networking 的 C# UDP transport、Schema handshake、DedicatedServerNetworkHost 和客户端 Replica API 索引。
  • 增加 INetworkServerRuntime 项目模块契约、Server Target 的 DedicatedServer.exe 入口，以及 NetworkDedicatedServer 示例的模块注册边界。
  • 将 Target 生成范围纳入项目 manifest 的 targets 契约；Server Target 不再对所有项目默认生成；.sharpproject 的 AddServerTarget/RemoveServerTarget shell verb 共用 Project Selector 命令并自动重新生成工程文件，项目 schemaVersion 仍为 3。
  • 登记胶囊体角色 Prefab 资产 ID、组件组成和内部引用重映射契约。
  • 更新角色 Prefab 为 mannequin skeletal mesh + Animator schema v3 与 locomotion state machine；胶囊 collider 仅提供 Trace，不生成渲染几何。
  • 增加 FBX provenance 字段和语义等价导出契约；明确导出文件不保证与来源字节一致。
  • 增加 SkeletalAnimationCompatibility 的显式绑定检查与 SkeletalAnimationRetargeter 的目标 Skeleton 资产契约；Retarget 不隐式发生。
  • 规定新增资源文件扩展名由语义类型小写化后加 s 前缀，并保留旧裸后缀和 .sharp... 后缀的兼容边界。
  • 修正输入修饰键位契约，并明确 Play 状态下 Runtime 输入与编辑器 Viewport 操作的隔离边界。
  • Windows 原生 WM_*BUTTONDBLCLK 现在会进入 Content Manager 的稳定双击动作路由；资产打开器契约和 schemaVersion 不变，自动化指针双击继续复用同一入口。
